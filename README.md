# Intelligent Automatic Voltage Regulator (AVR) Using Machine Learning

A beginner-friendly **Python simulation project** that demonstrates how machine learning can help regulate an unstable supply voltage and keep the simulated output close to 230 V.

> **Important safety note:** This is an educational software simulation only. It does not control real mains electricity, transformers, relays, or power electronics. Do not connect this code to household AC mains or use it as a real voltage regulator. Real AVR hardware requires isolated sensing, protection circuits, qualified design, and supervised testing.

## 1. Project idea

The input supply voltage may rise or fall because of supply fluctuations and load changes. An Automatic Voltage Regulator (AVR) compensates for these changes.

This project uses a **Random Forest machine-learning regression model** to estimate the compensation voltage required. A simple simulated plant then applies the correction and calculates the regulated output voltage.

### Example
- Input voltage: 205 V
- Predicted compensation: approximately +25 V
- Simulated output: approximately 230 V

The exact values depend on the load and the trained model.

## 2. Main features

- Generates a reproducible synthetic training dataset.
- Trains a Random Forest regression model.
- Predicts the compensation voltage.
- Simulates an AVR response for changing input voltage and load.
- Compares the ML controller with a basic no-compensation baseline.
- Saves model metrics, predictions, and a voltage-response graph.
- Includes a small automated test.


## 6. How it works

1. **Voltage sensing (simulated):** The program receives input voltage, load current, and temperature values.
2. **Dataset preparation:** Synthetic examples are created across a range of supply and load conditions.
3. **Machine learning:** A Random Forest model learns the relationship between operating conditions and the compensation voltage.
4. **Voltage correction:** The model predicts a correction. The simulation applies it, with a safety limit on the correction amount.
5. **Output evaluation:** The program records the regulated output and compares it with the 230 V target.

## 7. Machine-learning details

- **Algorithm:** Random Forest Regressor
- **Inputs:** Input voltage (V), load current (A), ambient temperature (°C)
- **Output:** Required compensation voltage (V)
- **Target voltage:** 230 V
- **Dataset:** Synthetic educational data generated by `src/generate_data.py`
- **Evaluation:** Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE)

The synthetic dataset is intended to demonstrate the workflow. It is not measured field data and should not be used to design or certify real electrical equipment.

## 8. Expected result

When you run the simulation, the terminal prints the model's MAE and RMSE and the average absolute output-voltage error. A graph is saved in `results/voltage_response.png`, showing the fluctuating input voltage and the simulated regulated output.

The output will not be perfectly constant because the simulation includes a small load-dependent voltage drop and model prediction error.

## 9. Limitations and future improvements

- Replace synthetic data with properly collected, isolated, verified laboratory data.
- Investigate alternative algorithms such as Gradient Boosting or a neural network.
- Add a time-series model for predicting voltage changes.
- For a real prototype, use a low-voltage isolated test setup and independent hardware over-voltage/over-current protection.
- Have all electrical hardware reviewed and tested by a qualified supervisor.
